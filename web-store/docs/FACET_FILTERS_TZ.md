# ТЗ: фасетные фильтры каталога

## Цель

Сделать фильтры каталога ближе к маркетплейсу: покупатель должен быстро сузить выдачу по категории, цене, бренду, наличию фото и важным характеристикам товара, не попадая в пустые или нерелевантные фильтры.

## Принципы

- Базовые фильтры доступны везде: цена, бренд, доступно к заказу, только с фото, сортировка.
- Категорийные фильтры показываются только там, где они уместны для текущей категории или уже активны в URL.
- Все параметрические страницы остаются `noindex, follow`; SEO-посадочные страницы делаются отдельно и осознанно.
- Текст наличия не обещает доставку день в день: товар доступен к заказу, доставка под заказ 7 дней.
- Первый рабочий слой использует уже доступные данные: название, публичное имя, бренд, фото, цену и извлекаемые признаки.
- Второй слой добавит нормальную модель характеристик `ProductAttribute` и backfill/ручное заполнение.

## Шаг 1: быстрый слой без миграции базы

- Расширить список `spec`-фильтров для популярных направлений: климат, холодильники, телевизоры, компьютеры, стиральные машины.
- Разделить фильтры на группы: `Климат`, `Холодильники`, `Телевизоры`, `Компьютеры`, `Стиральные машины`, `Общие`.
- Показывать группы в UI, чтобы список не выглядел случайным набором чекбоксов.
- Сохранить текущий URL-формат `spec=value` для совместимости.
- Бренд заменить с одиночного выпадающего списка на чекбоксы с поддержкой нескольких значений `brand=value&brand=value`.
- Покрыть тестами нормализацию, релевантность по категории и построение Prisma `where`.

## Шаг 2: модель характеристик

- Добавить таблицу `ProductAttribute`: товар, ключ, значение, нормализованное значение, числовое значение, единица, источник.
- Добавить конфиг фильтров по категориям: тип фильтра, ключ характеристики, подпись, порядок, SEO-флаг.
- Сделать backfill из названий и существующих полей товара.
- Позже подключить ручное редактирование в админке.

## Шаг 3: счётчики и UX

- Добавить счётчики рядом с фильтрами.
- На desktop оставить фильтры в левой колонке.
- На mobile оставить липкий блок `Фильтры` / `Категории`, активные фильтры показывать чипами.
- Кнопку наличия переименовать в `Доступно к заказу`.

## Шаг 4: SEO-посадки

- Оставить случайные фильтры закрытыми от индексации.
- Добавить отдельные индексируемые посадочные страницы для проверенных популярных фильтров.
