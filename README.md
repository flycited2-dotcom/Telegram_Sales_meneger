# Telegram Sales Agent 🤖

Умный Telegram-бот, который ведёт себя как настоящий менеджер по продажам.  
Построен на **Groq Llama 3.3-70B** (бесплатный tier) + **python-telegram-bot**.

---

## Что умеет

| Функция | Описание |
|---|---|
| 💬 Консультация | Отвечает на вопросы по наличию, ценам, скидкам |
| 🛒 Оформление заказа | Уточняет данные клиента, создаёт заказ в БД |
| 📤 Уведомление поставщика | Мгновенно пишет поставщику в Telegram или на email |
| 🔒 Резервирование | Обрабатывает ответ поставщика, ставит товар в резерв |
| 📩 Обратная связь клиенту | Сообщает клиенту о подтверждении / резерве / проблемах |
| 📋 История заказов | Клиент может запросить список своих заказов |

---

## Быстрый старт

```bash
# 1. Клонировать и установить зависимости
pip install -r requirements.txt

# 2. Создать файл .env
cp .env.example .env
# заполни TELEGRAM_BOT_TOKEN, GROQ_API_KEY, SUPPLIER_TELEGRAM_CHAT_ID

# 3. Запустить
python main.py
```

---

## Настройка `.env`

```env
TELEGRAM_BOT_TOKEN=...        # токен бота от @BotFather
GROQ_API_KEY=...              # бесплатный ключ: https://console.groq.com

SUPPLIER_TELEGRAM_CHAT_ID=... # chat_id поставщика (узнай через @userinfobot)
SUPPLIER_EMAIL=...            # email поставщика (резервный канал)

MANAGER_NAME=Алексей          # имя менеджера, отображаемое клиентам
COMPANY_NAME=ТехноТрейд       # название компании
```

## Команды бота (для клиентов)

| Команда | Действие |
|---|---|
| `/start` | Приветствие |
| `/orders` | Мои активные заказы |
| `/clear` | Сбросить историю диалога |
| `/help` | Справка |

## Протокол поставщика

Бот отправляет поставщику сообщение вида:

```
🔔 НОВЫЙ ЗАКАЗ ORD-AB12CD34

Товар: Ноутбук Dell Inspiron 15 × 3 шт.
Клиент: Иван Иванов / +7 900 123-45-67
...

Ответьте одной из команд:
ПОДТВЕРЖДАЮ ORD-AB12CD34
РЕЗЕРВ ORD-AB12CD34
ОТМЕНА ORD-AB12CD34
```

После ответа поставщика бот автоматически уведомит клиента.

## Структура проекта

```
├── main.py          # Telegram-бот: хэндлеры и запуск
├── sales_agent.py   # Claude-агент: системный промпт, инструменты, цикл
├── database.py      # Async SQLite: заказы, история диалогов
├── config.py        # Конфигурация из .env
├── data/
│   ├── products.json  # Каталог товаров (редактируй под свой ассортимент)
│   └── sales.db       # База данных (создаётся автоматически)
└── requirements.txt
```

## Добавление товаров

Отредактируй `data/products.json`. Пример записи:

```json
{
  "id": "SKU-001",
  "name": "Название товара",
  "description": "Описание",
  "price": 10000,
  "stock": 5,
  "unit": "шт",
  "category": "Категория",
  "supplier_sku": "ARTCL-001",
  "discounts": {
    "5+": 5,
    "20+": 10
  }
}
```

Перезапустите бота — каталог перечитается автоматически.
