# Telegram Training Bridge

Этот мост позволяет обучать бота прямо в Telegram: бот задает администратору вопросы, администратор отвечает эталонными фразами менеджера, ответы сохраняются в обучающие файлы.

## Почему внутри текущего бота

Нельзя безопасно запускать второй polling-скрипт на том же Telegram bot token, пока работает основной бот. Два процесса начнут конкурировать за `getUpdates`.

Поэтому обучение встроено в текущий бот как админский режим. Клиентские сообщения не затрагиваются. Если режим обучения активен в админском чате, ответы администратора сохраняются как обучение и не отправляются в sales-agent.

## Команды

| Команда | Что делает |
| --- | --- |
| `/train_start` | Запускает все вопросы по всем блокам |
| `/train_topics` | Показывает список доступных тем и количество вопросов |
| `/train_start round2` | Второй расширенный раунд без повторения первого набора |
| `/train_start greeting` | Только приветствия |
| `/train_start refrigerator` | Холодильники и связанные ошибки |
| `/train_start conditioner` | Кондиционеры |
| `/train_start generator` | Генераторы |
| `/train_start water_heater` | Бойлеры и водонагреватели |
| `/train_start washing_machine` | Стиральные машины |
| `/train_start microwave` | Микроволновки |
| `/train_start tv` | Телевизоры |
| `/train_start hood` | Вытяжки |
| `/train_start dishwasher` | Посудомойки |
| `/train_start checkout` | Оформление заказа |
| `/train_start selection` | Выбор позиции из списка |
| `/train_start complaint` | Жалобы и восстановление диалога |
| `/train_start listing` | Выдача вариантов и "еще" |
| `/train_status` | Показывает прогресс |
| `/train_skip` | Пропускает текущий вопрос |
| `/train_stop` | Останавливает обучение |

## Как отвечать

Бот пришлет вопрос такого вида:

```text
Клиент пишет: «Привет»

Ответьте так, как должен ответить сильный менеджер.
Если нужны 2-5 вариантов фразы, разделите их символом |.
```

Можно ответить одной фразой:

```text
Здравствуйте. Что подобрать по технике?
```

Можно ответить несколькими вариантами:

```text
Здравствуйте. Что подобрать по технике? | Добрый день. Напишите товар и бюджет, подберу варианты. | Приветствую. Что ищем?
```

## Куда сохраняется

| Файл | Что внутри |
| --- | --- |
| `data/sales_training_examples.csv` | Таблица для будущих правил, тестов и prompt examples |
| `data/training_sessions.jsonl` | Сырой журнал всех ответов с chat_id, темой и временем |

При новом `/train_start` бот смотрит в `data/sales_training_examples.csv` и пропускает вопросы, на которые уже есть сохраненный `good_reply`. Это работает и после рестарта сервиса: CSV считается источником уже пройденного обучения.

## Как использовать дальше

1. Набираем 100-300 живых эталонных ответов.
2. Из CSV делаем deterministic rules и тестовые сценарии.
3. LLM оставляем для живости языка, но бизнес-решения принимает код.
